# orion-ann-wasm

Initial browser interface for replaying native Orion search traces. This stage
loads diagnostics; it does not load graph caches, construct indexes, or execute
search in the browser. Windows support remains a later task.

## Build and validate

The bindings also compile on the host so rust-analyzer can analyze them alongside
the native workspace without a target override or an extra Cargo feature:

```bash
cargo check --locked -p orion-ann-wasm
```

Host compilation checks types; JavaScript interop still runs in a WASM environment.

From the workspace root, install `wasm32-unknown-unknown` for Rust 1.92 and a
`wasm-bindgen-cli` version matching `wasm-bindgen` in Cargo.lock, then run:

```bash
cargo build --locked -p orion-ann-wasm --target wasm32-unknown-unknown
wasm-bindgen --target web --out-dir target/wasm-replay \
  target/wasm32-unknown-unknown/debug/orion_ann_wasm.wasm
cargo run --locked -p orion-ann --example export_trace -- target/native-trace.json
```

Load the generated ES module in a Web Worker and initialize it before use:

```javascript
import init, { TraceReplay } from './orion_ann_wasm.js';
await init();
const replay = new TraceReplay(traceJson);
try {
  const metadata = replay.metadata();
  const firstPage = replay.nextEvents(32);
  replay.seek(0); // event offset; does not resume or rerun search
  const ids = replay.resultIds(); // owned Uint32Array copy
  console.log(metadata, firstPage, ids, replay.truncated);
} catch (error) {
  console.error(error.code, error.operation, error.message, error.details);
} finally {
  replay.free();
}
```

`position` and `eventCount` are read-only properties. Read to `eventCount` to
consume the captured prefix; `truncated` distinguishes that prefix from a full
trace. No borrowed WASM-memory views escape the interface. Errors use the same
`code`, `operation`, `message`, `details` and `causes` report as native Orion.

The CI smoke test executes the browser-target glue and the actual WASM module
in Node's WebAssembly VM, comparing every event, final result and an error report
against a trace generated by native Orion. This is runtime validation, not a
claim of cross-browser testing. Native error types and trace schemas have one
shared definition. The WASM dependency graph excludes the native engine,
ParlayANN, Rayon and mmap.

Next: isolate a portable production search path for small prebuilt graphs,
then add browser execution tests and SIMD128. Multithreading and resumable search
are separate follow-ups; replay controls do not imply either capability.

This crate is private (`publish = false`); no package is released.
